# Interndom – Internship Awareness System

A mobile app design that helps students discover, apply for and track internships,
while recruiters post internships and manage applicants.

## Features
### Student
- Welcome, login and sign-up
- Role selection (Intern/Student or Recruiter/Company)
- Browse and search internships with category filters
- Apply with cover letter and resume upload
- Track applications with a progress timeline
- Withdraw an application
- Student profile with skills, experience and resume

### Recruiter
- Company dashboard
- Post a new internship
- View applicants and shortlist or reject
- Manage job posts
- Company profile
